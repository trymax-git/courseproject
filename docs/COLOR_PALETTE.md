# Цветовая палитра SAASUNG Shop

## Обзор

Проект использует современную синюю цветовую палитру, разработанную для обеспечения отличной читаемости, доступности и визуальной привлекательности.

## Основные синие цвета

### Primary Blue
- **Переменная**: `--primary-blue`
- **Значение**: `#2563eb`
- **Использование**: Основной цвет для акцентов, кнопок, ссылок
- **Контрастность**: WCAG AA (4.5:1 на белом фоне)

### Secondary Blue
- **Переменная**: `--secondary-blue`
- **Значение**: `#1e40af`
- **Использование**: Темно-синий для заголовков, важных элементов
- **Контрастность**: WCAG AA (7:1 на белом фоне)

### Accent Blue
- **Переменная**: `--accent-blue`
- **Значение**: `#3b82f6`
- **Использование**: Светло-синий для hover состояний, интерактивных элементов
- **Контрастность**: WCAG AA (4.5:1 на белом фоне)

### Dark Blue
- **Переменная**: `--dark-blue`
- **Значение**: `#1e3a8a`
- **Использование**: Очень темный синий для фонов, контрастных элементов
- **Контрастность**: WCAG AAA (7:1 на белом фоне)

### Light Blue
- **Переменная**: `--light-blue`
- **Значение**: `#dbeafe`
- **Использование**: Светло-голубой для фонов, подсветки
- **Контрастность**: Используется только для фонов

## Нейтральные цвета

### Белый и серые оттенки

- `--white`: `#ffffff` - Основной белый цвет
- `--gray-50`: `#f9fafb` - Очень светлый серый (фоны)
- `--gray-100`: `#f3f4f6` - Светлый серый (фоны)
- `--gray-200`: `#e5e7eb` - Светлый серый (границы)
- `--gray-300`: `#d1d5db` - Средне-светлый серый
- `--gray-400`: `#9ca3af` - Средний серый
- `--gray-500`: `#6b7280` - Средне-темный серый
- `--gray-600`: `#4b5563` - Темный серый (текст)
- `--gray-700`: `#374151` - Очень темный серый (текст)
- `--gray-800`: `#1f2937` - Почти черный (заголовки)
- `--gray-900`: `#111827` - Самый темный (основной текст)
- `--black`: `#000000` - Черный

## Цвета состояний

### Success (Успех)
- **Переменная**: `--success`
- **Значение**: `#10b981`
- **Использование**: Успешные операции, подтверждения
- **Контрастность**: WCAG AA

### Error (Ошибка)
- **Переменная**: `--error`
- **Значение**: `#ef4444`
- **Использование**: Ошибки, предупреждения об опасности
- **Контрастность**: WCAG AA

### Warning (Предупреждение)
- **Переменная**: `--warning`
- **Значение**: `#f59e0b`
- **Использование**: Предупреждения, важные уведомления
- **Контрастность**: WCAG AA

### Info (Информация)
- **Переменная**: `--info`
- **Значение**: `#3b82f6`
- **Использование**: Информационные сообщения
- **Контрастность**: WCAG AA

## Обратная совместимость

Для обеспечения обратной совместимости со старым кодом, старые переменные маппятся на новые:

- `--dark-blue-color` → `--blue-900`
- `--blue-gray-color` → `--blue-800`
- `--sea-blue-color` → `--accent-blue`
- `--light-gray-color` → `--gray-200`
- `--white-color` → `--white`
- `--black-color` → `--black`
- `--gray-color` → `--blue-800`
- `--bright-blue-color` → `--blue-800`
- `--bright-lightblue-color` → `--blue-600`
- `--bright-support-blue-color` → `--blue-50`

## Рекомендации по использованию

1. **Текст на фоне**: Используйте `--gray-900` для основного текста на белом фоне
2. **Заголовки**: Используйте `--secondary-blue` или `--gray-800` для заголовков
3. **Акценты**: Используйте `--primary-blue` для кнопок и важных ссылок
4. **Hover состояния**: Используйте `--accent-blue` для hover эффектов
5. **Фоны**: Используйте `--light-blue` или `--gray-50` для светлых фонов

## Проверка контрастности

Все цвета проверены на соответствие стандартам доступности WCAG:
- **WCAG AA**: Минимальный контраст 4.5:1 для обычного текста
- **WCAG AAA**: Контраст 7:1 для важного текста

Используйте инструменты проверки контрастности при добавлении новых цветовых комбинаций.
